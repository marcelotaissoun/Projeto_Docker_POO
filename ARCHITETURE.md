# Classes Principais:

- app
    - Contém o núcleo (CORE) e todas as classes que existem para que ele funcione. É estático, e não deve sofrer grandes alterações
    
- db 
    - Contém o script necessário para criar o banco de dados

- interfaces
    - Contém as interfaces do projeto

- screens
    - Contém as telas estáticas criadas via scene builder
