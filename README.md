# Projeto_Docker_POO
Montagem de uma loja virtual de e-commerce. O back-end foi feito em Java com database em SQL (gerenciado pelo MariaDB), e o front-end em JavaFX.

Eu (Marcelo) e meu colega Marcos desenvolvemos o front-end em JavaFX e as funcionalidades principais, criando interfaces, exceptions, lógicas e plugins do microkernel em Java. O resto (microkernel, banco de dados) foi disponibilizado pelo professor como base do projeto.
